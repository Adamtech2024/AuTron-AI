**This part of document provides a detailed breakdown of the AuTron AI lineup, including performance profiles, model configurations, and core purposes for each version.**

## 🏆 AuTron 4 Ultra
**The Flagship: Maximum Intelligence & Strategic Synthesis**
The most powerful version, designed for complex problem-solving and multi-layered reasoning.

- **Fast (350M)**: Rapid responses for simple queries.
- **Think (1.2B + 700M)**: Strategic synthesis for analytical problems.
- **Pro (1.2B + 1.2B)**: Advanced dual-brain reasoning for professional tasks.
- **Ultra (1.2B + 2.6B + 700M)**: Triple-brain flagship mode for maximum complexity.
- **Extra (1.6B)**: Specialized model for niche logic handling.

## 💎 AuTron 4 Prism
**The Advanced Middle-Ground: Performance & High Intelligence**
Balanced for users who need high-tier intelligence with faster processing than the flagship.

- **Fast (350M)**: Quick response mode.
- **Think (1.2B + 1.2B)**: Deep reasoning via dual 1.2B models.
- **Pro (1.2B + 2.6B)**: High-intelligence mode using the powerful 2.6B primary.
- **Ultra (Standardized)**: Supports advanced synthesis logic same as the flagship.

## ⚡ AuTron 4o (Omni) (**NEW!**)
**The Web Specialist: Real-Time Intelligence & Global Synthesis**
The all-encompassing flagship version optimized for live web searching and multi-source integration.
- **Normal (SmolLM 1.7B)**: A unified, high-logic engine that handles both real-time web data extraction and final response synthesis in a single pass.
- **Search-First Logic**: Specifically tuned to parse live search results and convert them into actionable intelligence instantly.

## 🌀 AuTron 4 Neo
**The Balanced Daily Driver: Reliable Logic**
Optimal for general purpose tasks, combining speed with sufficient intelligence for everyday use.

- **Fast (700M)**: A more capable baseline than Nano or Leaf.
- **Think (1.2B + 700M)**: Solid reasoning for detailed explanations.
- **Pro (1.2B + 700M)**: Integrated thinking profile for versatile usage.

## ⚙️ AuTron 4 Nano
**The Performance Small Model: Snappy & Efficient**
Optimized for low-latency and performance-heavy environments where speed is key.

- **Fast (350M)**: The fastest possible response time.
- **Think (700M + 350M)**: Efficient synthesis for mid-tier logic.
- **Pro (700M + 700M)**: Performance duo for reliable small-model output.

## 🍃 AuTron 4 Leaf
**The Lightweight Edition: Eco-Friendly & Nimble**
Designed for minimalist resource usage and extreme portability.

- **Fast (350M)**: Lightweight baseline.
- **Think (350M + 350M)**: Basic dual-brain synthesis.
- **Pro (350M + 350M)**: Sustainable intelligence profile.

## 📊 Shared Features (Universal Engine)
All versions share these core capabilities:
- **Centralized Knowledge**: Synchronized storage in `\.autron-storage\`.
- **Turbo Search**: High-speed parallel web research.
- **AI Builder**: One-click standalone Python AI generation.
- **Auto-Learner**: Background research and facts integration.
- **Transparency**: `/show` and `/show-msgs` commands in every version.
